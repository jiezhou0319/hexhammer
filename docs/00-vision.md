## 一句话

**三国志 11 的实时行军与接触战 + 钢铁雄心 4 的暂停指挥 + 英雄无敌的将领养成，
装在中古战锤的世界观里**：一张持久大地图上，你占领点、攒资源、造棋子、养将领；
暂停时从容下令，放行后棋子按各自的充能节奏移动、接战、反击——你掌握时间的流速，
直到占领全图。

## 设计支柱（不动摇的五条）

1. **一张持久大地图，征服即游戏**
   不是一场场离散的遭遇战，也不是内政大战略：地图本身就是游戏。
   占点给资源，资源变成棋子，棋子推进战线。胜利 = 占领全图（留多条件接口）。
   局长由地图与城/资源点数量**涌现**：图大城多则长、图小城少则短，首发精调中图。
   锚点：三国志 11（单图实时行军）、HOMM（地图探索与滚雪球）。

2. **实时暂停制：暂停下令，放行兑现（自驱的心脏）**
   全局脉冲时钟持续运转（1x 下每脉冲约 1~2 秒、多档变速）；每枚棋子按各自的
   移动费/攻击费独立充能，攒满即行动。随时暂停、从容下令、随时改令——
   没有回合边界、没有意图锁定。战斗自动进行：主动攻击、被动反击、脱战过路费、
   包围减益，全部由规则自驱兑现。你从不点"结算"，你只决定时间走多快。

3. **将领是一枚特殊的棋子，不是无敌的主角**
   将领不统辖任何兵力——**一枚棋子就是一个兵**，将领只是其中特殊且足够强的一枚：
   四维更高、可佩装备、可用技能，但走与普通棋子完全相同的规则
   （充能/反击/脱战/士气），围殴能堆死。
   装备给属性或技能；死亡可复活但要足够的账期与大成本；部分装备阵亡掉落。
   RPG 感来自养成与损失，不来自无双。
   **随机性向将领倾斜**：兵对兵伤害走公式、**可复现**（固定随机种子下重放一致），
   仅保留小幅方差（±15% 浮动与命中/暴击默认值，07 §1）；大骰子只活在将领的
   技能与施法里（成功率、伤害浮动、前摇打断）。

4. **确定性战场 + 位置博弈**
   小兵伤害走完整计算公式（快、可读、碾压时自然速胜）；士气是**确定性的包围减益**
   （4 面被围降攻防、6 面重降），不掷骰、不溃逃。
   战锤味保留在：兵种功能克制、冲锋、恐惧类 debuff 技能、将领魔法。
   放弃桌规的：rank/banner、逐模型摆放、满屏 d6、掷骰崩溃测试。

5. **个人可完成的范围 · 纯 PvE**
   只做单机 vs AI（不做对战/热座/网络）；首发单派系（AI 同派系换色）、
   地图尺寸可配置（首发精调中图）、程序化美术起步；AI 首发只要"会造兵占点平推"，
   难度靠数据旋钮（收入乘数/白名单/反应延迟等），不做视野作弊。

## 核心循环（一局的呼吸）

```
   ┌────────────── 暂停（无时间压力，随时进入）──────────────┐
   │  收入入账（账期）→ 造兵排队 / 建附属 / 买装备            │
   │  → 下令：移动 / 攻击 / 撤退 / 施法 / 开关自动还手        │
   └───────────────────────┬───────────────────────────┘
                           ▼
   ┌────────────── 放行（脉冲时钟自动推进）─────────────────┐
   │  棋子按移动费/攻击费充能行动：前进 1 格 / 主动攻击      │
   │  被打立即反击 · 离开敌邻格付过路费 · 包围度→士气减益    │
   │  将领技能掷骰 · 账期到点经济结算                        │
   └───────────────────────┬───────────────────────────┘
                           ▼
                随时再暂停 …… 直到占领全图
```

## 范围边界（首发明确"不做"）

| 不做 | 替代方案 |
| --- | --- |
| 对战 / 热座 / 真网络 | 纯 PvE：单机 vs AI（标准局 1 玩家 + 2 AI） |
| 内政 / 建筑树 | 3~4 种资源 + 主城附属建筑解锁指定兵种 |
| 跨局战役 / 小队成长线 | 单局内将领养成闭环（等级/装备/复活） |
| 单挑 / 俘虏子系统 | 后续版本再评估 |
| 掷骰士气 / 溃逃 | 确定性包围减益（4 面/6 面） |
| 玩家回放 | headless 确定性保留为内部测试/自战工具 |
| GW IP 词汇 | 全自创名词（见 docs/06 §10） |
