## 一句话

**三国志 11 的行军与接触战 + 英雄无敌的带兵与养成，装在中古战锤的世界观里**：
一张持久的大地图上，你占领点、造棋子、养将领；每回合给棋子下达意图，
点过回合后所有势力同时行动、接触的棋子自动厮杀——你在关键瞬间拍板，
看着战场按你的规划展开，直到占领全图。

## 设计支柱（不动摇的五条）

1. **一张持久大地图，征服即游戏**
   不是一场场离散的遭遇战，也不是内政大战略：地图本身就是游戏。
   占领点给钱，钱变成棋子，棋子推进战线。胜利 = 占领全图（未来扩展其他胜利法）。
   锚点：三国志 11（单图行军）、HOMM（地图探索与滚雪球）。

2. **规划-结算分离（自驱的心脏）**
   回合内你从容下"意图"（棋子去哪、什么姿态、将领放什么技能）；
   点过回合后全部势力（含 AI）同时结算，接触战自动进行——
   玩家从不点"攻击"按钮，只在关键点暂停拍板（接战棋子是否后撤、将领施法目标）。
   棋子不会被一回合秒杀：战斗是持续数回合的拉锯，援军与撤退有窗口。

3. **将领是一枚特殊的棋子，不是无敌的主角**
   将领不统辖任何兵力——**一枚棋子就是一个兵**，将领只是其中特殊且足够强的一枚：
   四维更高、可佩装备、可用技能，但走与普通棋子完全相同的规则
   （意图/ZOC/接战/围攻/脱离/溃逃），围殴能堆死。
   装备给属性或技能；死亡可复活但要足够的回合数与大成本；部分装备阵亡掉落。
   RPG 感来自养成与损失，不来自无双。

4. **公式互砍，骰子留给关键时刻**
   小兵伤害走完整计算公式（快、可读、碾压时自然速胜）；
   骰子只出现在将领技能/施法（成功率、伤害浮动）与士气崩溃。
   战锤味保留在：兵种功能克制、冲锋、恐惧与崩溃、将领魔法；
   放弃桌规的：rank/banner、逐模型摆放、满屏 d6。

5. **个人可完成的范围**
   首发单派系（AI 同派系换色）、地图尺寸可配置（首发精调中图）、
   程序化美术起步、AI 首发只要"会造兵占点平推"。

## 核心循环（一局的呼吸）

```
   ┌─────────────────── 规划阶段（无时间压力）───────────────────┐
   │  收入结算 → 造兵/买装备（主城特化）→ 给棋子下意图（点位+姿态）  │
   │  → 给将领下技能指令 → 点【结束回合】                            │
   └────────────────────────┬───────────────────────────────────┘
                            ▼
   ┌─────────────────── 结算阶段（可逐事件观看）──────────────────┐
   │  全势力同时移动 → 接触自动开战（公式互砍+技能骰）→ 崩溃/溃逃   │
   │  ★ 关键点暂停：己方接战棋子去留？将领施法目标？                │
   └────────────────────────┬───────────────────────────────────┘
                            ▼
                     下一回合 …… 直到占领全图
```

## 范围边界（首发明确"不做"）

| 不做 | 替代方案 |
| --- | --- |
| 内政/建筑树 | 主城"特化"选方向解锁高级兵 |
| 多派系 | 单派系跑通，AI 换色 |
| 跨局战役/小队成长线 | 单局内将领养成已闭环（等级/装备/复活） |
| 单挑/俘虏子系统 | 后续版本再评估 |
| 真网络对战 | 单机 vs AI + 热座 |
| GW IP 词汇 | 全自创名词 |
