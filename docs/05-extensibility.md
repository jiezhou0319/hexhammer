# 05 · 扩展性设计：为未来留的每一扇门

> **状态：待审（2026-10-06 自 docs/archive 恢复）**——门 1~8 的"留口不实现"原则与
> 最终定位无关，大体仍成立；其中门 1 的"仅英雄可带"已按"棋子即兵"修正。
> 文内代码引用（`scripts/ui/`、`M1-Txx` 编号）按现行状态另议。
>
> 原则：不为未来写代码，但为未来留接口。每扇门写清"现在是什么、将来怎么打开、不要现在做什么"。

## 门 1 · 新兵种 / 新武器 / 新派系 —— 已开

- **现在**：复制一个 .tres 改数值即可进场（M0 已具备）
- **将来**：注册表扩容后支持条件规则（如"某兵种专属装备/技能"）、组合规则
- **别做**：为"将来可能的属性"提前加字段——等第二个使用场景出现再抽象

## 门 2 · 新特殊规则 —— 半开（M1-T10 验收）

- **现在**：`rule_id` → 引擎内注册表分发（frenzy/fear 已就位）
- **将来**：规则超 10 条（M3 预计触发）→ 重构为"规则组件"：每条规则一个 .gd 实现
  `apply_on_charge / modify_attacks / on_wound_dealt` 等钩子接口，引擎只在固定点位广播钩子
- **别做**：现在就做钩子框架——两条规则用不到抽象，YAGNI

## 门 3 · 战役 / 小队成长 —— 接口已定

- **现在**：UnitState 是纯数据，战役层将来包一层 `CampaignRoster`（持久队伍），
  战斗时把 roster 条目转成 UnitProfile 实例入场，战后把战果写回
- **关键留口**：UnitProfile（模板）与 UnitState（战场实例）已经分离——成长系统改的是
  "roster 条目生成 profile 的过程"，不污染战斗引擎
- **别做**：不要在 UnitState 上加经验/等级字段（那是 roster 的事）

## 门 4 · AI —— 命令层即接口

- **现在**：AI = 产出 `Command` 序列的函数，`engine.execute` 照单全收（校验会拒绝非法命令）
- **将来**：L0 随机 / L1 启发式 / L2 脚本 / L3 模拟搜索，都只是"换命令生产者"；
  模拟搜索直接复用纯函数解算器（不开场景）
- **别做**：不要给引擎加"AI 钩子"——命令层已经是边界，加钩子反而耦合

## 门 5 · 回放 / 网络对战 —— 同一扇门

- **现在**：命令 + seed = 完整战局（M1-T9 回放器证明）
- **将来**：异步网络对战 = 交换命令文件；lockstep 实时 = 交换命令消息 + seed 同步。
  UI 不用改，因为引擎入口只有命令
- **别做**：任何"为网络准备的状态镜像"——现在不做就不做

## 门 6 · Modding —— 数据即模组

- **现在**：`resources/` 全 .tres；Wesnoth 证明"内容皆数据"最终会长出 addon 生态
- **将来**：`pck` 打包用户数据目录 + 启动时扫描加载（Godot 原生 ProjectSettings 覆盖机制即可，不需要自写加载器）
- **风险预案**：若 .tres 对玩家太不友好（ADR-3 后果），加 JSON 导入层——数据类不变，只动序列化，成本可控
- **别做**：M3 之前不做任何 mod 菜单/管理器

## 门 7 · 本地化 —— 事件流即文案源

- **现在**：日志/UI 文案是英文硬编码
- **将来**：M1 的事件对象化后，所有战斗文案从事件参数生成——届时把"事件→文案"的函数
  换成查翻译表即可；UI 静态文案抽 key（M5）
- **别做**：现在不做 tr() 包裹（没本地化文件时是噪音）

## 门 8 · 美术升级 —— 渲染器即隔离层

- **现在**：第一代程序绘制（MapRenderer._draw）
- **将来**：第二代 TileMapLayer + 单位场景，只重写 `scripts/ui/`；事件流已经把"发生了什么"
  和"怎么演"分开（M1-T1 之后动画=事件的消费者）
- **别做**：不要在第一代 UI 上做美术债（画得再好看也会扔）

## 反模式清单（出现即停）

1. 在 `ui/` 里写游戏规则 → 违反分层（验收：删 ui 测试仍绿）
2. 绕过 Command 直改 BattleState → 关掉回放/网络/AI 三扇门
3. 在规则代码里散落 randi() → 破坏确定性
4. "顺手"加的属性字段没有第二个用例 → 数据模型腐烂的开始
5. 硬编码任何 GW 专有名词（包括注释里）→ 发布时的法务炸弹，从一开始就不留
