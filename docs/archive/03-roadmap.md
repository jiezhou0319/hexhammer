# 03 · 路线图：里程碑与验收标准

> 原则：每个里程碑结束都是一个**能打开就玩**的版本，而不是一堆半成品系统。
> 顺序不可调换：规则闭环 → 数据闭环 → 表现闭环 → 智能 → 内容 → 打磨。

## 总览

```
M0 技术验证(已完成) ──► M1 规则闭环 ──► M2 数据与表现闭环 ──► M3 战役层 ──► M4 AI ──► M5 打磨发布
     spike 34测试        "一场完整对战"      "像游戏了"          "有进度感"     "能单挑电脑"    "能给人玩"
```

## M0 · 技术验证 spike ✅（2026-10-05 完成）

**问题：Godot + 六边形 + 战锤式解算，这条路走得通吗？**
产出：纯逻辑层 + 命令层 + 第一代 UI + 34 单测全绿 + headless 跑法打通。
结论：走得通，架构三原则（分离/数据驱动/纯函数）确立。详见 docs/02。

## M1 · 规则闭环 —— "一场完整对战"（预计 2~4 周）

**定义**：两个熟练玩家热座打完一场有胜负、有翻盘、有故事的对战，规则无失真硬伤。

### 范围
1. **事件对象化**（ADR-7）：BattleEvent 体系替代字符串日志——后续一切功能的地基
2. **冲锋响应三选一**：hold / stand & shoot / flee（当前只有 hold，是最大规则失真）
3. **射击视线与掩护**：森林/丘陵遮挡（参考 godot-hexgrid 的 LOS 实现）
4. **心理学补完**：恐慌测试（25% 击伤触发）、溃逃单位 rally 测试
5. **近战战果分**：替换当前"伤害数对比"为完整战斗决议（冲锋+1、侧背袭 +1/+2 —— skirmish 简化版）
6. **胜利条件系统**：全灭之外增加"击溃点"（敌 50% 价值溃逃即胜）与撤退点
7. **存档/读档**：BattleState 序列化（回合边界 bug 是战旗最深的坑，Wesnoth 前车之鉴，M1 就必须做冒烟测试）
8. **回放**：命令序列 + seed 重放（命令模式的第一个红利）

### 验收
- [ ] 一场 3 势力混战从布阵到判定胜利无人工干预跑完（headless 脚本）
- [ ] 冲锋响应/恐慌/追逃全部有单测
- [ ] 存档→读档→继续打→结果与不存档路径一致（seed 相同）
- [ ] 新增一条特殊规则（Hatred 重投命中）不改任何现有文件的逻辑分支（只加数据+注册表条目）

## M2 · 数据与表现闭环 —— "像游戏了"（预计 3~5 周）

**定义**：不看代码的人愿意打开玩第二局。

### 范围
1. **hex 核心 addon 化**：`core/hex` → `addons/hexhammer`（对齐 godot-hexgrid 惯例，独立可复用）
2. **第二代 UI**：TileMapLayer 六边形瓦片 + 单位场景 + 移动/冲锋/射击动画 + 骰子结果飘字
3. **军队名单系统**：ArmyList .tres（点值上限、兵种上限）+ 部署阶段（放兵）
4. **地图数据化**：MapDef .tres 替代 Voronoi 随机（随机生成保留为一种来源）
5. **剧本格式**：`scenarios/*.tres` = 地图 + 各方名单 + 部署区 + 胜负条件
6. **工具：批量自战模拟器**：`tools/autobattle.gd` headless 跑千场随机对战出平衡报表（Tessera 思路，给调数值用）

### 验收
- [ ] 玩家自组 500 点名单 vs 默认名单可完整开打
- [ ] 新增一张手工地图不改任何代码
- [ ] 自战 1000 圄出报表：各兵种胜率贡献/平均存活回合（数据进 docs/balance/）
- [ ] 删除 `scripts/ui/**` 后测试仍全绿（分层纪律的持续验证）

## M3 · 战役层 —— "有进度感"（预计 4~6 周）

**定义**：输了想再来一局，赢了想养下一个英雄。

### 范围
1. **小队成长**：Mordheim 式——英雄/杂兵战后经验、升级、战伤（永久属性损益）
2. **战利品与装备**：武器/神器池、装备槽（数据结构已就绪）
3. **战役剧本**：3~5 个连续遭遇战 + 分支（基于 scenarios 扩展 campaign .tres）
4. **队伍存档**：战役级进度存档（区别于单场战斗存档）
5. **规则效果注册表扩容**：规则数预计超 10 条，按 ADR-6 预案重构

### 验收
- [ ] 一条完整战役线（3 战）可通关，队伍属性跨战保留
- [ ] 战利品掉落与装备更换全程数据文件驱动
- [ ] 新增一条战役剧本不改 C++/GDScript 主干

## M4 · AI —— "能单挑电脑"（预计 3~4 周）

**定义**：电脑方会在正确时机冲锋、集火、撤退，打得像一个忙碌的朋友。

### 范围（对齐 Wesnoth 的 AI 分层哲学）
1. **L0 随机合法**：跑通"AI=命令生产者"管线（架构红利，工作量小）
2. **L1 启发式**（默认 AI）：威胁评估（可被冲锋格/可被集火值）、简单集火与保人（英雄光环利用）
3. **L2 战术脚本**：每回合评估表驱动的战术倾向（激进/防守/保英雄），剧本可指定
4. **L3 模拟搜索**（stretch）：用解算器快速前向模拟 N 步（纯函数层的红利），仅限关键决策点
5. **AI 自战调参**：M2 的模拟器 + L1/L2 对打，平衡性回归测试

### 验收
- [ ] 1v1 人机对战 AI 全阶段行动无非法命令
- [ ] AI 自战 100 场无崩溃无死锁（回合机压力测试）
- [ ] 一局人机对战体验报告：AI 至少展现集火、撤退两种行为

## M5 · 打磨发布 —— "能给人玩"（预计 3~4 周）

1. 音效/音乐（免费素材 + 事件驱动）、视觉打磨（地形变体、单位朝向）
2. 教学关（第一个剧本=教学）、本地化框架（UI 文案抽 key，Godot 翻译系统）
3. 设置（难度/动画速度/日志详略）、export 模板（Windows 优先，itch.io 发布候选）
4. modding 最小文档：如何加一个兵种（对齐 Wesnoth "平台不是产品"愿景）
5. 发布前 IP 自查：全部名词去 GW 化清单（法务红线）

### 验收
- [ ] 新玩家 15 分钟内完成教学关并理解冲锋/士气
- [ ] itch.io 页面构建包可下载运行
- [ ] 按 modding 文档，第三方（拉一个朋友）能成功加一个自创兵种

## 里程碑外的持续纪律

- 每个任务合入前：测试绿 + 无新增 `push_error` + demo 场景可玩
- 平衡调整一律走 `tools/autobattle` 报表，不拍脑袋
- 每个里程碑收尾写 `docs/retro/Mx.md`` 五行复盘（超期原因/砍掉什么/下期改什么）
