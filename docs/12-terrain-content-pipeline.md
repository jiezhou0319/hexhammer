## 0. 一句话总纲

**地图上没有"一片森林"这种资产——森林是配方（recipe）：地表材质 + 贴地覆盖物 + 格子主角物 + 群系调色，四层内容物分四条管线生产，由散布系统在运行时组装。** AI 生成的需求单位是配方里的每个物件，永远不是"一片地形"。

## 1. 美术方向（定调，改动慎重）

**"被诅咒的神圣罗马帝国"**：16~17 世纪中欧的低饱和阴暗版，一切夸张到 11。

1. 色彩：低饱和大地色（铁灰/暗绿/泥褐/石灰白）；高饱和暖色只留给火（营火/熔岩/窗光/燃烧的废墟），冷色只留给魔法与极北。
2. 垂直夸张：山更尖峭、林更密高、废墟巨大；巨物地标是地图记忆点。
3. 战争痕迹即叙事：烧村、绞刑架、骸骨堆、褪色军旗——每格都在讲故事。
4. 群系即"被诅咒的省份"（意象保留、名词自创，见 §6 群系表）。
5. 雾是灵魂：体积雾 + 低角度斜阳从第一天进管线。

**参照**（按价值排序）：TWWH3 Immortal Empires 战役地图（头号，连续地形+群系+地标的现役最佳实践）、Vermintide 材质语言、Battle Brothers 色彩分级（个人可达的证明）、King Arthur: Knight's Tale、HOMM3/Songs of Conquest、Manorlords、GW 军书羊皮纸地图（战役 UI 层用）、画师 Adrian Smith / Ian Miller / John Blanche / Jakub Rozalski（巨物构图）、桌游 terrain 台面实拍。

**AI 生成边界（硬约束）**：
- AI 生成：棋子、T1~T4 内容物、贴图。单体、不拼接、容错高。
- **绝不生成：地形网格本身**。地形 = 高度场 + 六边形逻辑层 + splat 着色器 + 程序散布，是一个系统。整块生成地形 mesh → 寻路高度判定/河流刻蚀/格子归属/LOD 全部死亡，WeGo 战旗的命根子没了。

## 2. 内容物分类学（体系骨架）

按**实例化方式 × 与格子逻辑耦合度**分五类。每类的生产管线、规格、AI 生成物形态完全不同：

| 类 | 名称 | 是什么 | 数量级/图 | 实例化 | AI 生成物 |
| --- | --- | --- | --- | --- | --- |
| T0 | 地表表皮 | 草/泥/岩/雪/沼泥/垄沟——**材质贴图，不是模型** | 全图连续 | terrain shader splat 混合 | **无缝贴图**（生图，非生模） |
| T1 | 贴地覆盖物 | 草丛/花/蕨/蘑菇/芦苇/碎石/骸骨小件 | 数千~数万 | MultiMesh 分桶 | 单体白模小件 |
| T2 | 格子主角物 | 树/枯木/巨石/麦垛/栅栏/绞刑架/神龛 | 数百 | MultiMesh 分桶 | 单体白模，每型 3~5 变体 |
| T3 | 结构物/占点 | 农舍/磨坊/瞭望塔/矿场/营帐/桥 | 数十 | 独立 Node3D（挂逻辑） | 单体白模或组合件 |
| T4 | 巨物地标 | 泰坦骸骨/矮人山门/腐龙尸骸 | 个位数 | 独立 Node3D + 远景可见 | 单体（AI 甜区，已拍板单独处理） |

## 3. 配方解构：森林与麦田到底怎么"制作"

**群系格子类型 = 配方**，不是资产。运行时由散布系统组装：

```
森林格 = T0 林下地表(苔泥+落叶 权重) 
        + T1 ×5~12(蕨/灌木/蘑菇 按噪声mask)
        + T2 ×3~7棵(云杉v1..v4 哈希轮换, 旋转/缩放抖动)
        + 群系调色(墨绿×±8%明度逐实例微扰)

麦田格 = T0 垄沟贴图(世界坐标投影, 方向自动一致)
        + T1 ×6~10(麦茬/野花 点缀)
        + T2 ×1~2(麦垛/草垛) + 田边栅栏段(边界规则)
        + 调色(成熟麦黄, 压饱和)
```

推论：**AI 生成的需求单位 = 配方里的每个物件**（"一棵云杉"，而非"一片森林"；"一张垄沟贴图"，而非"一块麦田"）。配方本身是 BiomeDef 数据，人写，永远不生成。

变体轮换：同类物件 3~5 变体 + 旋转 + 缩放区间 + 逐实例色扰，是"同类格子不重样"的全部秘密——视觉丰富度是**排列组合**出来的，不是资产堆出来的。

## 4. 风格统一：三道闸（把 AI 抽奖变成生产线）

1. **白模原则**：AI 只出形状。生成时限定 low-poly / flat shading；入库时**弃用 AI 贴图**只留 mesh。
2. **统一材质替换**：全部换项目自写 `PropMaterial`（shader）——按材质槽（干/叶/石/金属/布/骨）映射群系调色板渐变 + 顶点色 AO + 逐实例 ±8% 明度/色相微扰。100 个来源不同的模型穿同一件制服，出来就是"一个美术做的"。**风格锁在着色器手里，不锁在 prompt 手里。**
3. **验收卡**（每模型过五项，可脚本化）：①比例符合规格书单位尺寸 ②原点贴地 ③朝向 +Z ④面数 T1<500 / T2<3000 / T3<15000（T4 自由）⑤法线朝外无破面。

规格书基准（**现行口径：1 格 = 外接圆半径 1.0**，即 `HexMath` 的 size 参数、格心间距 √3 ≈ 1.732；spike 期"格心距 1、外接圆 1/√3"的 KayKit 对齐约定已随 KayKit 废弃，2026-10-10 入库更正）：树高 1.2~2.0 格、巨石 0.5~1.0 格、农舍 1×1 格内、麦垛 0.4 格。详细数值随垂直切片校准后冻结。

## 5. 数据结构与渲染管线（Godot 侧）

```
BiomeDef (.tres, ADR-3 数据驱动)
├─ palette: 5~8 色（地表主/副、植被主/副、点缀、雾、太阳偏移）
├─ ground: [贴图A, B, C] + 权重规则（海拔/坡度/湿度 → splat）
├─ scatter_T1: [{model, 密度/格, scale区间, 噪声mask}]
├─ scatter_T2: [{model, 槽位数/格, 规则（如森林=3~7棵）}]
└─ atmosphere: 雾色/雾密度/太阳色/环境色偏移
```

- **地形 mesh（现行实现已落地）**：`HexTerrainBuilder` 纯函数产出顶面/边带/角落三段几何 → chunk 化 ArrayMesh，相邻格共享顶点坐标（文明6 式无缝连续地形）；顶点色走 arrays 直写。六边形逻辑层（选中/步费/归属）的现行可视载体 = 内顶面扇形高亮（`hex_highlight.gd`，M1a-T7）；文明6 式"淡格线层"主线尚未实现，spike 有已验证参考件（notes/spike-1007-salvage.md §1.1）。spike 期 SurfaceTool 顶点色全黑、无方向光隐形两坑的实测记录移至同笔记 §2。
- **terrain shader（目标形态）**：现行材质侧 = 材质槽映射 + BLEND 权重过渡（M1a+，换 style 不改世界事实）+ T8 已定的世界平面 UV 投影；本条 splat 按海拔×坡度×湿度混合（陡坡自动露岩、山顶自动积雪）为后续升级方向。
- **散布**：`hash(格子坐标 + 盐)` 确定性散布（同种子同图，无需存摆位）→ 按类分桶 MultiMeshInstance3D（每桶 1 draw call；中图 64×48 ≈ 3 万实例无压力）。哈希参考件见 notes/spike-1007-salvage.md §1.3。
- **河流**：~~高度场刻蚀河谷~~ **ADR-14 已拍板（2026-10-10）：格边河流**——稳定边/角图 + 排水映射，为 T3 前置；贴地水面 mesh 与"渡口=咽喉逻辑位"仍有效。
- **分层纪律**（对齐 docs/02）：BiomeDef/散布表/资产清单为纯数据；散布算法属内容物生成，落 `scripts/content/`（现行 map_generator/map_io 同层）纯函数可 headless 单测；渲染进 `scripts/ui/`。

## 6. AI 生成工作流（每个模型的旅程，六步）

```
需求清单(§7) → prompt 模板批量生成 → 4 选 1 人工挑(人当美术总监)
→ 自动后处理(减面/弃贴图/换材质/原点比例校正, Blender 脚本化)
→ 入库(assets/props/<群系>/<类>/<名>_v#.glb + 清单表登记 tag)
→ 挂散布表(资产替换不动代码)
```

### 6.1 三路供给（2026-10-07 定稿：KayKit 彻底移除，来源无关是硬性质）

| 供给路 | 定位 | 适用 |
| --- | --- | --- |
| 在线生成（Meshy 7 / Tripo / Rodin） | 质量件 | T3 建筑、T4 地标、棋子、首批定调件——额度花在刀刃上 |
| **本地生成（Hunyuan3D 2.1，本机 RX7700XT 12GB）** | 量产件 | T1/T2 变体量产，无限抽奖零成本 |
| 程序化（Blender 脚本 / 几何节点） | 规则件 | 碎石/栅栏段/岩壁等规则形状，脚本比生成+验收快；兼垂直切片占位 |

- 本地生成可行的前提正是 §4 白模原则：本地与在线的差距在贴图，形状已够用；
  形状生成约 10GB 显存（优化后 3~6GB），贴图阶段 20GB+ 从不需要。
  AMD/Windows：~~先试 ROCm 原生 PyTorch wheel，不行走 ComfyUI-ZLUDA~~ **已落地（2026-10-07）**：comfyui-rocm 底座 + TheRock nightly ROCm 栈，部署实录见 docs/13 §9。
- 四路汇入同一条入库流水线（验收卡→弃贴图→换 PropMaterial），
  风格统一靠制服不靠来源 → 配比随时可调，首发 ~100 模型中在线额度
  预计只需 T3/T4 + 定调件约 10~15 个。

- **Prompt 骨架**（风格词库固定，只换物件描述——一致性第一来源）：
  `low-poly stylized {物件}, single game asset, flat base, centered, front view, muted desaturated colors, grimdark dark fantasy, medieval warhammer inspired, no background, no texture detail`
  贴图（T0 另走生图）：`seamless tileable texture, {草甸/泥地/岩面}, desaturated, painterly, top-down, no vignette`
- **工具分工**（2026-10 现状）：模型 Meshy 7（质量）/ Tripo（速度+免费额度）/ Rodin（细节）；贴图 SD/MJ seamless 模式。风格引导用图参考模式喂垂直切片定调图。
- **资产清单表**（JSON/tres）：id、类别、群系、变体号、规格检查结果、来源 prompt——可追溯可替换。
