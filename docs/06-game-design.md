# 06 · 游戏设计总纲（GDD v0.3）

> 本文是 2026-10-05 设计访谈（五批问答 + 两次模型澄清）的**全部拍板决策**，按主题整理。
> v0.3 关键澄清：**一枚棋子就是一个兵**——没有"将领带兵"结构、没有编制系统、没有兵数条；
> 将领只是场上特殊且足够强的一枚棋子。它替代 v0.2 及之前一切"棋子/带兵"表述。
> 它是当前唯一权威的设计来源；与旧文档（archive/）冲突处以本文为准。
> 每节末尾的【待细化】是下一层设计问题，进入开发前逐个击破。

## 1. 外形与规模

| 项 | 决策 |
| --- | --- |
| 游戏类型 | 单张持久大地图上的回合制征服（WeGo：规划-结算分离） |
| 锚点游戏 | 三国志 11（行军/接触战/将领）+ 英雄无敌（带兵/养成/地图滚雪球）+ 战锤世界观 |
| 地图 | 尺寸可配置：小 40×30 / 中 60×40（首发精调）/ 大 100×60 |
| 势力数 | 标准局 3 势力（1 玩家 + 2 AI），可配置 |
| 棋子规模 | 每方 10~30 枚棋子（其中将领 1~3 枚）。**一枚棋子 = 一个独立作战单位**：兵种决定属性、有自己的 HP；没有"将领带兵"的从属结构，将领也是一枚棋子 |
| 一局时长 | 中图 2~3 小时，可存档分段 |
| 胜利条件 | 占领全图（架构留多条件接口：未来点数胜利/目标建筑等） |
| 视野 | 探索迷雾：未去过黑雾、去过常亮但无实时敌情（侦察有价值，不会互蹲） |

## 2. 回合结构（自驱的心脏）

### 规划阶段（无时间压力，随便改）
1. 收入自动入账（上回合占点产出）
2. 经济操作：招募棋子（即时/队列）、买装备、主城特化
3. 给每枚棋子下**意图**：目标点位（单点+自动寻路，显示预览路径）+ 姿态
4. 给将领棋子下技能/施法指令
5. 点【结束回合】

### 棋子意图（极简指令集）
- **目标点位**：单点 + 自动寻路（自动绕开敌 ZOC 与障碍；绕不开时走最近路径并在
  预览中标出"会被拦截的位置"）
- **姿态**（四选一）：
  - `进攻`：接敌就打，敌脱离时自动追击
  - `防守`：原地固守，被打还手，加防御
  - `风筝`：自动与敌保持距离，远程优先（骑弓/弓箭的灵魂姿态）
  - `撤退`：自动远离最近敌人移动

### 结算阶段（逐事件推进，可快进，见 §3 完整时序）
全势力同时执行意图 → 接触自动开战 → 伤害轮 → 士气 → 决策点暂停 → 追击/溃逃。
战斗**跨游戏回合持续**：接上的棋子每回合结算时互砍一轮，直到一方溃逃/被歼/脱离——
所以拉锯战有窗口调援军、下回合再决策。

## 3. 结算时序与战术涌现（v0.2 新增，本次访谈核心产出）

> 原理：WeGo 下"包抄""断后"不是按钮，是**多个意图 + 接战规则涌现的结果**。
> 玩家操作"方案"，引擎用规则兑现战术。

### 3.1 脉冲式移动（"同时行动"的具体实现）
结算按**段（脉冲）**推进：每一段内，所有"移动中"的棋子按**速度降序**各走
`每段步数` 格（速度 8 = 每段 2 格，速度 4 = 每段 1 格），走完或被拦截为止。
- 天然涌现：快兵先到（骑兵先抄人）、先接触先接战、同格争抢按段内顺序
- 完全确定 → 可回放、可测试
- 画面：所有棋子逐段挪动（可快进），像看一盘自己下过的棋自动走

### 3.2 ZOC（控制区）——防线与绕后成本的基石
- 任何存活棋子的 6 个相邻格 = ZOC（全姿态，不分敌我阵营规则统一）
- 敌军进入我 ZOC → **必须停下，双方接战并钉住**
- 友军棋子：可穿过、不可停留（同格）
- ZOC 让"防线/卡位/断后"成立，绕后必须真正绕路（成本换收益）

### 3.3 接战钉住（engagement pin）
- 接战中（与敌相邻交战）的棋子：本结算内**不能移动**，只能挨打/还击/脱离
- 这是包抄的前提：敌人被钉住不能转身，侧后才会暴露
- 上一回合已接战的棋子：本回合规划时不能下移动意图（只能换姿态/等脱离决策），
  UI 上明示"已接战"

### 3.4 围攻计数（简化版朝向系统，不做六向朝向实体）
- 一支棋子的**接战面上限 = 2**：最多被两个方向的敌军有效围攻；
  第 3 支敌军只能相邻"候战"（不参与伤害、也不被打）
- 第 2 方向起：围攻方伤害加成（数值待校准）、被围方士气测试递减
- 侧/背不区分：**多方向 = 被包抄**

### 3.5 战术操作如何涌现（两个标准推演）

**包抄**（操作=规划时两次点击）：
```
规划：刀盾A → 目标点E正面邻格，进攻    （钉住它）
      骑枪B → 目标点E侧后方格，进攻    （绕过去）
结算：段1~2 B(速8)绕行、A(速4)逼近
      段3 A 抵E正面 → 接战，E 被钉住
      段4 B 抵E侧面 → 第2方向 → 围攻加成
      伤害轮：A 常规输出、B 加成输出、E 士气带围攻惩罚 → 崩溃溃逃
风险：若 A 未钉住前 B 先到，E 可能先打 B；E 的增援意图可能反围 B —— 棋味所在
```

**撤离**（三种）：
```
① 未接战：姿态=撤退 → 自动选远离最近敌人的方向移动
② 接战中（决策点暂停）：继续交战 / 尝试脱离
   脱离 = 必成功，但对方全部接战棋子各打一次"追击打击"（伤害打折）
   脱离后本结算剩余段向后方移动
   敌姿态=进攻 → 自动追击：速度差决定追不追得上；追上=重新接战+脱离方士气惩罚
③ 全线后撤：多队同下撤退姿态；接战队逐个在决策点选脱离；
   留一队断后钉住敌人掩护主力 —— 断后是涌现战术，不是机制
```

### 3.6 每次结算的完整时序
1. **意图锁定**：收集全势力棋子意图与将领指令
2. **脉冲移动段**：按 §3.1 执行直至全员走完/被拦/全部接战
3. **技能/施法轮**：将领指令按速度序施放（掷骰判定）
4. **伤害轮**：所有接战配对打一轮（公式+围攻计数）
5. **士气轮**：崩溃测试（兵力损失阈值/恐惧技能/围攻惩罚）→ 溃逃移动+追击
6. **决策点**：己方接战棋子弹"继续/脱离"（可设全自动）；将领可施法时弹目标选择
7. **结算收尾**：占领判定（走入无主/敌方设施格）→ 收入预览 → 下一回合

【待细化】段数与每段步数的具体参数（速度 4/6/8 对应表）；追击移动的段内规则；
"候战"棋子的自动补位时机；同格争抢的详细优先级；风筝姿态的保持距离参数与
目标切换逻辑；防守姿态的防御加成数值。

## 4. 战斗解算

| 层 | 方式 |
| --- | --- |
| 兵对兵互砍（伤害轮主体） | **伤害公式**（确定性为主，轻浮动）：攻方攻击 vs 守方防御 → 扣 HP；克制系数修正 |
| 围攻 | 多方向接战：伤害加成 + 士气递减（§3.4） |
| 将领技能/施法 | **掷骰**：成功率判定 + 伤害浮动（骰子给关键时刻，战锤味所在） |
| 士气 | 掷骰崩溃测试：HP 损失过阈值/被恐惧技能打击/被围攻时测，失败→溃逃 |
| HP 恢复 | 医疗棋子战场治疗；驻城缓慢回血 |

- 一场典型接触战：势均力敌打 **3~6 个游戏回合**（棋子 HP 足够厚，互砍是 HP 消耗战）；
  **伤害碾压时自然速胜**（不人为拖）
- 公式输出：每伤害轮双方各损失多少 HP

【待细化】公式骨架（攻防减法/比值结构、克制系数、浮动范围 0.85~1.15 量级）。

## 5. 兵种体系（首发 7 种 + 医疗，功能矩阵）

**每枚棋子即该兵种的一个独立作战单位**：兵种给属性带（攻/防/速/HP），棋子各自上场各自挨打，互不从属。

| 兵种 | 定位 | 战术功能 |
| --- | --- | --- |
| 骑枪 | 冲锋类 | 高冲量首击，长枪克制它；快棋，包抄/追击主力 |
| 骑弓 | 风筝轻骑 | 移动中输出、伤害低、打了能跑；最快的风筝执行者 |
| 刀盾 | 近战肉盾 | 抗线、扛冲锋、伤害平庸；钉住敌人/断后的主力 |
| 长枪 | 反骑 | 对冲锋类反制，对其他平庸；防线骨架 |
| 弓箭 | 远程主力 | 伤害高于骑弓但脆、被贴脸废 |
| 法师 | 弓箭类变体 | 远程技能伤害（掷骰）、群体/控制法术；自身极脆 |
| 工程机械 | 攻城 | 打人低、打建筑/城强 |
| 医疗 | 辅助 | 无伤害，战场治疗/驻城回血 |

- 每个兵种有**普通/精锐**两档棋子：普通各主城可造，精锐需主城特化（见 §6）——精锐=更高属性的同类棋子

【待细化】每个兵种四维数值带（攻/防/速/HP）、克制矩阵系数、精锐档数值差。

## 6. 经济与生产（反内政设计）

| 项 | 决策 |
| --- | --- |
| 收入 | 占领的城镇/资源点每回合产钱（【待细化】设施类型与数值：城/镇/矿） |
| 普通棋子 | **即时招募**：钱到棋到，但**当回合不能移动 + 初始 50% HP**（新兵需整备） |
| 精锐棋子 | **招募队列**：花若干回合训练，落地即满血（且上限更高） |
| 主城特化 | 不做建筑树。主城本体造普通棋子；给主城指定特化方向（骑兵营/弓箭营……）后解锁对应精锐。**建设=选方向，不是点科技** |
| 装备 | 商店购买，装给将领棋子（加属性或加技能） |

【待细化】特化成本与规则（可否改特化、上限）、钱的其他去向、初始配置（开局送什么棋子）。

## 7. 将领（RPG 载体）

| 项 | 决策 |
| --- | --- |
| 定义 | **将领就是一枚棋子**——一个特殊的兵：更强的四维、个人血量、可佩装备、可用技能。**不统辖任何兵力，没有带兵/编制概念**；他与普通棋子唯一的区别是"特殊且足够强，但能被围殴死" |
| 与普通棋子同规则 | 走同一套意图（点位+姿态）、ZOC、接战、围攻、脱离、溃逃——不搞双系统 |
| 成长 | 等级/属性成长（战斗经验）；装备加属性或**附加技能** |
| 死亡 | 不永久：**足够回合数 + 大成本**复活（痛感与容错平衡） |
| 掉落 | 阵亡时**部分装备掉落**在战场（可被拾取：损失不完全，RPG 循环加钩子） |
| 技能 | 主动施法/战术技能（结算的技能轮触发，掷骰）+ 被动加成（如光环） |

【待细化】将领属性表、将领来源（开局赠送/城中雇用/战场事件）、首发技能清单（5~8 个）、经验曲线、复活公式、掉落概率。

## 8. AI（首发最低可用）

- 首发目标：**会玩经济 + 平推**——占点、造兵、特化城、组队推向玩家
- 架构铁律：AI 与玩家走**同一套意图系统**（产出同样的"点位+姿态+技能指令"），
  包括同样的 ZOC/钉住/围攻规则——AI 也会包抄和追击，因为规则涌现对双方对称
- 战术深化（集火残血、守要地、识破包抄）后续版本迭代

## 9. 派系（首发）

- **单派系**跑通全部循环，AI 同派系换色
- 派系系统按"数据文件"预留（差异=数值偏移+独有兵种+独有将领技能）

## 10. 明确保留的战锤味 / 放弃的桌规

| 保留 | 放弃 |
| --- | --- |
| 兵种功能克制（长枪反骑等） | rank/banner/接战线（无模型摆放） |
| 冲锋概念（骑枪首击加成） | 逐模型 d6 解算（WS/S/T 满屏骰） |
| 恐惧/崩溃/溃逃（士气是第二战场） | 冲锋响应三选一（WeGo 下无"响应"时点） |
| 将领魔法（技能掷骰） | 风魔骰/八风体系（简化为将领技能资源） |
| 围攻、断后、追击的战锤式涌现 | 六向朝向系统（用围攻计数替代） |
| 世界观与美术氛围 | GW 专有名词（法务红线，全自创） |
