| 项 | 决策 |

## 2. 时间与指令模型（自驱的心脏）

### 2.1 全局脉冲时钟与暂停
- 不暂停时全局脉冲时钟自动推进：1x 速度下每脉冲约 1~2 秒（定标待拍），多档速度可调；
- **随时暂停**：暂停期间自由下令、查情报、移镜头、开关自动还手；恢复放行后按新指令执行；
- **原子性**：单次行动的数值结算一旦开始不可打断，暂停在该次结算完成后生效——
  这为将来的速度裁定（如 2 秒/脉冲或 1 秒/脉冲）保留了干净的实现空间；
- **账期**：每 N 脉冲为一个账期（N 待拍）。收入入账、生产队列推进、附属修复等经济
  结算按账期进行；战斗与移动按脉冲、经济按账期，两层时钟。

### 2.2 充能轴（"黄条"）
- 每棋子两条独立充能轴：**移动费**与**攻击费**——按兵种定的两个数字（例：骑兵 4、步兵 8）；
- 轴满即行动一次：**移动动作 = 沿路径前进 1 格**；**攻击动作 = 主动攻击当前目标**；
- **移动期间攻击轴不充能**（停下才能开火）——风筝的真实成本与节奏来源：
  快兵迅速机动到位，再按自己的攻击速度开打；
- **首次攻击半费**：到战场后的第一刀只需半轴，补偿攻方集结等待；
- 无指令待机时轴照常充满但**空转消耗**，不积攒行动；
- UI：每棋子一条血量 + 一条黄条（**当前轴**的充能百分比）；视野内敌方同样可见；
- 同脉冲多棋子触发行动：**按势力序（玩家先结算），同势力内按棋子 ID（创建序）写死**——
  结算完全确定、可测试。

### 2.3 指令
- **实时生效、随时可改、无锁定窗口**：指令即"下一步行为"，改令无惩罚；
- 指令集：**移动**（目标点位 + 自动寻路）、**攻击**（指定目标）、**撤退**
  （= 远离敌人的移动指令）、**施法**（将领，带前摇，见 §3.5）、
  **自动还手开关**（默认开；关 = 挨打不反击）；
- 框选/编组/批量下令为 RTS 操作标配（具体形态见 UI 待细化）。

## 3. 战斗规则

### 3.1 主动攻击
攒满攻击费 → 出手，全额伤害，吃全部修正层（克制/冲锋/盾墙/校射等既有乘区照旧）。

### 3.2 反击（被动、立即）
- **被打后立即反击**，不等充能——即时触发的行为，不消耗自身攻击轴；
- **反击率（触发门槛，2026-10-09 拍板）**：被打时按当前反击率掷骰决定是否触发
  ——近战高/远程低（测试值见 10 §3）；每次触发后当前率 **−5% 累计**，每脉冲
  **+1% 平滑恢复**（上限=基础值），多敌围攻下反击频率自然滑落，防无限免费反击；
  掷骰属兵对兵小幅方差口径（种子固定可复现，00 支柱三）；
- 伤害**恒低于主动攻击**：按兵种反击系数（08 表新列；与反击率正交——率管触发、
  系数管伤害）；
- **反击射程 = 自身射程**：弓箭在 4 格外射步兵，步兵够不着 → 不反击；
  步兵贴脸砍弓箭，弓箭以很低的伤害反击；
- 只有**有反击能力**的兵才会反击；"自动还手"开关（默认开）控制是否执行；
- **脱战过路费不受反击率影响**（§3.3"至少 1 下"是确定代价，保证软控制可靠）。

### 3.3 脱战与"过路费"（软控制区 · 口径 B）
- **ZOC 与接战钉住已移除**：进入敌军邻格免费、可在邻格自由停留/通过；
- **从敌军邻格移开时**，该敌立即对你造成一次**普通反击伤害（不吃任何额外加成）**；
- 相邻几个敌军就吃几下（至少 1 下）——被围时撤退天然更痛；
- 战术含义：防线不再靠"必停"而靠"过路费"——断后 = 留在敌邻格里持续收税；
  穿插袭击后排 = 按路径付血税，快兵的价值与代价同在。

### 3.4 冲锋（tag 触发制）
- 冲锋是可施加的 **tag**，不是专属规则分支；
- **标准触发**：骑枪移动 ≥2 格后接敌 → 伤害**立即结算**（不等攻击费）；
- 技能可施加冲锋 tag（例：将领点技能后移动 1 格即视为冲锋）——多条件可叠加触发；
- 冲锋伤害倍率沿用首轮 ×2（数值待按新口径重校）；
- **衔接规则（2026-10-09 拍板）**：冲锋结算视为**首攻**——触发 tag 即消耗"首次攻击
  半费"权益（冲锋本身不看轴、立即结算；同四掷口径，命中/暴击/浮动均掷）；冲锋后
  攻击轴从当前值（移动期间冻结，通常为 0）开始正常充能，下一刀**全额费**；
  技能施加的冲锋 tag 同口径。节奏校验见 10 §2（骑枪"强在单发与机动，不强在攻频"）。

### 3.5 施法与前摇
- 施法 = 带**前摇**的动作（前摇期间不移动）；
- **可被打断**：打断条件按技能各自定义——某些任意伤害即断、某些打到血线才断；
  打断与防打断本身是玩法与决策点；
- 成功率判定与伤害浮动**掷骰**在此：**随机性的主居所是将领线**（00 支柱 3；
  兵对兵仅保留四类小幅方差：±15%/命中/暴击（§4 表）与反击率（§3.2））。

### 3.6 士气（确定性包围系统）
- **无掷骰、无崩溃测试、无溃逃、无 Ld 属性**；
- 每脉冲结算**先算士气**：相邻敌军 ≥4 面 = 士气降低、6 面全包围 = 严重降低；
- 效果 = 按百分比降低攻防（具体百分比待拍）；
- 包围度是围攻的继任者：包抄的价值从旧"围攻伤害加成"变成"攻防减益 + 脱战多收费"。

### 3.7 战术涌现（新规则下的标准推演）
- **包抄**：多方向围住目标 → 4 面减益 + 目标离格要多份过路费；
- **断后**：断后棋子站在敌邻格不动，追兵每绕一格都付税；
- **风筝**：骑弓移动期间攻轴冻结——停下充攻轴开火的那段窗口就是追兵的机会。

### 3.8 每脉冲结算顺序
1. **士气更新**（先结算，已拍）；
2. 本脉冲触发的行动按势力序（玩家先）→ 同势力棋子 ID 序逐个结算（移动/攻击/施法）；
3. 反击与脱战过路费随对应事件即时触发；
4. 账期到点 → 经济结算（收入/队列推进/修复）。

## 4. 战斗解算

| 层 | 方式 |
| --- | --- |
| 兵对兵 | **伤害公式**（07 v5 比值模型不变：`ATK²/(ATK+DEF)` + 乘法修正链），±15% 浮动 / 命中 / 暴击 / 反击率触发**四类小幅方差拍板保留**（2026-10-09） |
| 反击 | 主动伤害 × 兵种反击系数（取代旧"远程被贴脸还手 ×0.5"） |
| 冲锋 | tag 触发，首轮 ×2（待重校） |
| 士气 | 确定性包围减益（§3.6） |
| 将领技能/施法 | **掷骰**：成功率 + 伤害浮动 + 前摇打断（骰子主居所） |
| HP 恢复 | 医疗动作治疗；驻城缓慢回血（参数待细化） |

- 修正层处置（v0.5）：**守减伤（防守姿态）删除、围攻 ×1.25 删除（包围士气继任）、
  贴脸 ×0.5 由反击系数继任**；克制 ×1.75 / 穿甲 / 盾墙 / 校射 / 破城 ×3 等既有乘区保留；
- 先手不再是规则：由充能轴涌现（攻费低者先出手）+ 反击即时；
- 战斗节奏锚点：旧"互砍 5 刀 / 拉锯 3~6 回合"按**脉冲口径重标**（待双费表后重校）。

时钟账期见 docs/10，开发期持续调整；仍待拍：冲锋 ×2 重校、医疗动作总量口径确认。

## 5. 兵种体系（首发 8 种）

**每枚棋子即该兵种的一个独立作战单位**：兵种给属性带，棋子各自上场各自挨打。

| 兵种 | 定位 | 战术功能 |
| --- | --- | --- |
| 骑枪 | 冲锋类 | 高冲量首击（移动 ≥2 格 tag 触发），长枪克制它；快棋，包抄/追击主力 |
| 骑弓 | 风筝轻骑 | 移动中接近、停下开火；攻轴冻结的风筝节奏执行者 |
| 刀盾 | 近战肉盾 | 抗线、扛伤害；盾墙减远程；邻格过路税收税人 |
| 长枪 | 反骑 | 对冲锋类反制（迎击重挂待拍），防线骨架 |
| 弓箭 | 远程主力 | 伤害高于骑弓但脆、被贴脸反击很低 |
| 法师 | 弓箭类变体 | 无视护甲的远程伤害（统一公式）、群体/控制法术；自身极脆 |
| 工程机械 | 攻城 | 打人慢（高攻费）、打建筑/城强 |
| 医疗 | 辅助 | 无伤害，治疗动作回血 |

- 每兵种**普通/精锐**两档棋子：普通各城可造，精锐需附属建筑解锁；精锐 = 更高属性的同类棋子；
- 旧数值带（08 v6.1 表）为**回合制口径参考**：速度列 → 拆分为移动费/攻击费两列、
  新增反击系数列、删除 Ld 列——全部待重锚（见 08 §0.5 重锚清单）。

【待细化】双费表、反击系数与能力位、迎击重挂、器械笨重是否由高攻费涌现、医疗重定标。

## 6. 经济与生产（多资源 + 附属建筑）

| 项 | 决策 |
| --- | --- |
| 资源 | **3~4 种分类型资源**（如 肉/金/铁，终表待拍）；占领的城与野外资源点产出**对应资源**；招兵吃对应资源组合 |
| 账期 | 每 N 脉冲一结：收入入账、队列推进、修复完成 |
| 落兵区 | 每座城 = 城格 + 周围一圈共 **7 格**；**逐格可选、逐格排队**；目标格被占则该单位落地等待 |
| 生产 | 队列制：花资源排队 → 按账期推进 → **满血落地**（"即时招募 50% 半血"旧案废除，生产时间即整备成本） |
| 附属建筑 | **仅主城可建**；解锁指定兵种的招募资格（与落兵区格子绑定——逐格可选的意义所在）；抢主城后附属**概率损坏**；**可修复**（半价、1 账期）；损坏率/成本随内容期定 |
| 队列归属 | 队列是己方投资：**主动取消退款；主城被抢队列取消且即将落地单位的花费不退**；无法获得敌方在建队列 |
| 装备 | 商店购买，装给将领棋子（获取结构待细化） |

反内政立场不变：没有建筑树、没有科技——建设 = 在主城摆附属解锁兵种，选方向不点科技。

【待细化】资源终表与城/点产出映射；兵种资源成本；附属建筑目录/成本/建造时长/损坏率；
账期长度；资源囤积上限；开局配置。

## 7. 将领（RPG 载体 + 随机性归属）

| 项 | 决策 |
| --- | --- |
| 定义 | **将领就是一枚棋子**：更强四维、个人血量、可佩装备、可用技能；走与普通棋子**完全相同**的充能/反击/脱战/士气规则，围殴能堆死 |
| 随机性归属 | **骰子集中在将领**：技能成功率、伤害浮动、前摇被打断、装备掉落——"兵对兵确定、将领有戏"，RPG 线承担高随机 |
| 技能接口 | 技能可施加 tag（冲锋等）——技能与战场机制的统一接口；技能数值/清单待细化 |
| 成长 | 等级/属性成长（战斗经验）；装备加属性或附加技能 |
| 死亡 | 不永久：足够账期 + 大成本复活（痛感与容错平衡） |
| 掉落 | 阵亡时部分装备掉落在战场（可被拾取） |

【待细化】将领四维重锚（与 08 数值带的量纲冲突仍开放）；技能清单（成功率/伤害浮动/打断条件/tag）；
装备槽位与获取结构；复活/掉落公式；经验分账与升级选择点。

## 8. AI（分层节律 + 数据旋钮 · 纯 PvE）

### 8.1 决策节律（什么时候想）
- **战略层，每账期一次**：经济分配、造什么兵、附属建筑、主攻方向；
- **战役层，每 5~10 脉冲**：兵团编组、推进目标、撤退整补——长线意图不轻易改；
- **战术层，事件驱动 + 轮询兜底**：被打/目标死/路径被堵/费将满前 1~2 脉冲预决策；
  无事件的棋子按轮询片定期扫一遍兜底。

### 8.2 计算预算（想多少）
- AI 全部在**脉冲间隙批处理**（脉冲结算完 → 下一脉冲开始前），不占渲染帧；
  **暂停时时钟不走、AI 静止**——暂停是玩家的特权；
- 寻路节流：只在指令变化或路径被堵时重算，行进中不重算；
- headless 自战 = 同一套 AI 快进脉冲（ADR-2 纯逻辑层红利），平衡报表持续可用。

### 8.3 反应延迟（多快反应）
AI 不同脉冲完美响应：被打后 1~2 脉冲才重估——既是拟人感，也是天然难度旋钮。

### 8.4 难度旋钮（全部为剧本/地图数据字段，首发 2~3 档）
| 旋钮 | 低难 | 高难 |
| --- | --- | --- |
| 收入乘数（每势力字段） | ×0.8 | ×1.2+ |
| 可造兵种白名单 | 只基础兵 | 全量 |
| 反应延迟 | 3~4 脉冲 | 0~1 脉冲 |
| 决策质量参数 | 故意分兵/无视后排 | 集火最优目标 |
| 开局加成 | 无 | 起始资源 + |

- **视野不作旋钮**：AI 与玩家同视野规则 + 记忆外推（侦察玩法对 AI 有效），
  AI 强度用上表五项调足，不做信息作弊。

### 8.5 架构铁律
- AI 与玩家走**同一套指令接口**——同样受反击/过路费/冲锋 tag/士气约束，行为天然可信；
- AI 评估**直接 import 战斗解算器**算预期结果，禁写近似公式（近似版会系统性误判
  克制与反击价值）；
- 分层混合架构：战略脚本 + 战术效用评分。

### 8.6 进场节奏
M1 随机合法 AI（验证内核）→ 经济落地做平推 AI → 打磨期深化。
纯 PvE 无热座，早期 AI 从"重要"变"必须"。

## 9. 派系（首发）

- **单派系**跑通全部循环，AI 同派系换色；
- 派系系统按"数据文件"预留（差异 = 数值偏移 + 独有兵种 + 独有将领技能）。
