## §1 裁决口径

**评委与输入**：GLM-5.3-Flash 对每个 seed 的四张灰度调试视图（`tools/terrain_debug_views.gd` 产出）逐 seed 裁决。渲染口径沿用该工具的「固定对照」规定（`tools/terrain_debug_views.gd:25-30`）：正交俯视数据面、窗口统一 1280×720、每格整六边形顶点色、材质 UNSHADED（灰度值=数据本身不受光照影响）、实际运行时渲染器 forward_plus。每份 stats 含四视图像素自检与两两差分防呆（全部 PASS，例见 `visual/terrain_debug_stats_worldfail_regions_mountains@24x16_11_forwardplus_1280x720.txt`）。

**灰度结构四项**（判据定义由裁决字段与证据文案归纳；验收意图对应执行计划 §9「能否辨认群山、宽谷、平原、孤峰」，`docs/M1a-terrain-T6-stylized-execution-plan.md:282`）：

| 判据 | 字段 | 通过标准（读图面） |
|---|---|---|
| 山系连贯 | `mountainsCoherent` | 山体成体系：主脊带支脉、峰簇与谷地明暗交替、脊线相连成山系；不读作散乱尖点或孤立浮纹 |
| 孤峰稀疏 | `peaksSparse` | 峰不散乱：平原上孤峰少量、大小一致、各自可辨（可作地标）；无成片噪点尖点 |
| 平原开阔 | `plainsOpen` | 平原成片：大片连贯平缓区（slope 视图纯黑连片），无碎斑切割、未被脊线切分 |
| 两大主导区 | `twoDominantRegions` | 山/平原两档大地貌区各自成块、边界可辨，仅凭灰度一眼可分（region 视图两档主导） |

**达标线**：四项全真。**与世界门的关系**：本裁决只覆盖灰度结构面，与 S5 世界门（REGION_DOMINANCE 等五枚检查）相互独立——12 个 worldfail seed 在本表中达标不改变其世界门未过状态（见 §4）。

3. **视觉过 ≠ 世界门过**：12/20 seed 仍是 S5 世界门未过样例（worldfail 夹具，首错多为 REGION_DOMINANCE）。本表达标只覆盖灰度结构四项，不应外推为世界生成质量整体达标。
4. **单后端单机**：stats 声明实际运行时渲染器 forward_plus（adapter=NVIDIA GeForce RTX 2050，Windows 10.0.26）；其余后端未测（Compatibility/mobile 未覆盖）。
