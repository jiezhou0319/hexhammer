## 排期总账与设计债门（2026-10-09 增）

### 总账与产能基线
- **产能基线**：**待主创自报**；暂按旧口径"每晚 2~3 小时 ≈ 每周 10~15 小时"占位。
  **M1a 收尾 = 第一次校准点**：用实际速度回填基线、重算下表；此后每期收尾 retro 时复读。
- **总账**：M1a 3~6 + M1b 3~5 + M2 4~6 + M3 4~6 + M4 3~5 + M5 3~4 = **20~32 周**；
  加单人项目中断 buffer（+25%）≈ **25~40 周（约半年~9 个月）**。
- **buffer 构成（2026-10-09 增注，评审 S6）**：约 1/3 为决策/评审预留——设计债门清零、
  retro、T13 对表拍板（拍板也是工时），其余为中断风险。
- **估时口径（2026-10-09 定，评审 S2；同日复审 N3 更正）**：04 的"半天/一天/两天" =
  **1.5/3/6 有效工时**（≈业余节奏一晚的专注量）；按 10~15h/周折算 M1a ≈ 2.5~4 周
  （总账 3~6 周内）、M1b ≈ 3.5~5.5 周（**上沿略超总账 3~5 周，超出量由 +25% buffer
  吸收，不另改总账**）——两段均以 M1a 实测回填为准；若改按全职 8h/日口径须整体重排。
- **超支阈值**（代替硬时间盒——单人业余硬盒不现实）：单期实际耗时超估算上限
  1.5 倍仍未达验收 80% → 触发砍范围重排，写进当期 retro。
- **砍段次序**（超预算时从下往上砍）：
  1. **不可砍不可延**：M1b——证伪关口，延 = 项目失去存在性判断；
  2. **不可砍可缩**：M2——核心征服循环；可缩 = 附属建筑/精锐档延后；
  3. **可分层缩**：M1a（砍序：美术并行分支 → 随机生成（保固定测试图）→ 高程降两档 →
     相机手感项（保边界钳制），与 04 排期建议对齐）、M3（地图精调/装饰缩，
     养成线尽量保）、M4（可缩至 L1 启发式）；
  4. **可并可砍**：M5（打磨可并 M4 尾；modding 文档/本地化可砍）。

  **砍段红线（2026-10-09 增，评审 S3）**：任何砍法不得击穿当期验收口径——

## M1a · 地形地基 —— "有地可站"（粗估 3~6 周，以实际速度校准）

**定义**：文明6 式**连续联动网格**的完整地基：带高程的地形在 60×40 图上可渲染、
可点选、可高亮，相机顺手（P0-范围-1 裁决：主创定向 M1a 先行，2026-10-09）。

**为什么先做**：地形与时间模型正交——M1b 若证伪出内核问题，地形零返工；
且是 ADR-13 两个 spike（拾取/相机）的前置。

> **证伪对冲（2026-10-09 评审 S1 增注；主创同日拍板）**：M1a 先行为主创拍板
> （P0-范围-1），保持；但两条例外对冲——① M1a 超支砍序固定"先表现后地基"
> （见排期总账砍段次序 3）；② **允许 M1a-T2（数据层）完成后并行启动 M1b-T1
> 脉冲时钟的平地粗沙盒**（色块棋子即可读出时间模型节奏）——若选择前移，
> 存在性判断可提前 2~4 周，M1a 表现层工作顺延不废弃。**何时启动 M1b 由主创在
> M1a 开发过程中视情况自行决定，不做硬性排期**（最早可在 M1a-T2 完成后并行）。

### 范围
1. **hex 数学重写**：axial 坐标 / 邻居 / 距离 / 朝向 + 单测（零恢复，全新实现）
2. **地图数据层**：尺寸 / 地形类型 / **高程分层（离散等级）** / 通行性；
   **数值修正只留扩展字段、不实现**（07 地形修正仍是待定项）
3. **连续网格生成**：程序生成带高程地形——邻格高差生成**悬崖面/斜坡连接**，
   无缝拼合（Civ6 式；ADR-13 2026-10-09 修订）
4. **拾取链路**：屏幕射线 → 对地形 mesh **物理 raycast** → 世界坐标 → axial
   （直接按带高程实现，无平地简化阶段）
5. **策略相机**：固定俯角、平移 / 缩放 / 边界钳制
6. **高亮系统**：每格半透明高亮 mesh（为 M1b 移动范围 / 路径预铺）
7. **材质槽体系 + 美术并行验证分支**：地形类型→材质映射，色块起步；并行分支上
   同接口可即换贴图试效果——主线不含贴图、后合并（主创 2026-10-09 并行思路）
8. **地图来源**：固定测试图 + 简单随机生成脚本（正式地图生成器 M3 再议）

### 明确不做（防膨胀）
- 地形对伤害/移动的**数值修正**（仅数据层留字段）
- **精细美术资产**（贴图/装饰走并行分支，不阻塞主线；棋子仍 3D 原语）

### 验收
- [ ] 60×40 带高程地图生成并渲染：邻格高差处为悬崖面/斜坡无缝连接，无破面
- [ ] 鼠标任意点选（含高程差格）拾取正确；相机平移/缩放/边界钳制顺手
- [ ] 任意格子集合高亮/取消无感知延迟
- [ ] hex 数学 / 数据层 / 拾取映射单测全绿（headless）
- [ ] 并行分支换一张贴图即见效果，主线代码零改动（材质槽接口验收）

## M1b · RTwP 内核证伪 —— "打得起来"（粗估 3~5 周）

**定义**：3 势力×4 兵种（刀盾/骑枪/弓箭/长枪）固定阵容**无经济沙盒**，1 玩家 +
2 随机合法 AI，打一场能读出节奏的实时暂停制战斗（P0-范围-2 裁决：3 势力早暴露
同脉冲多方结算争抢）。**本段是整个项目的证伪关口**——RTwP 时间模型若不成立，
在这里翻，回 00 重议。

### 范围
1. **脉冲时钟**：全局时钟、1x=2s（10 §4 测试值）、多档变速、随时暂停
   （原子性：单次结算完成后暂停才生效）
2. **双充能轴**：移动费/攻击费独立充能、首攻半费、移动期间攻轴冻结、空转消耗
3. **指令系统**：实时生效 / 随时改令 / 撤退 / 自动还手开关
4. **移动执行**：寻路（通行性硬约束 + 代价函数接口，**地形/高程修正值本期恒 0**——
   挂 M1a 扩展位、M3 拍板后才填，2026-10-09 评审 C7 厘清）+ 每次前进 1 格；
   **脱战过路费**（离开敌邻格时，每个相邻敌一下普通反击伤害）
5. **战斗管线**：07 v6 公式 + 增减伤钳制 [0.2, 4.0] + 浮动/命中/暴击/反击率四掷；
   兵种反击系数（10 §3 测试值）；**即时反击**（不耗攻轴、射程=自身射程、能力位）
6. **冲锋 tag**：骑枪移动 ≥2 格接敌即时结算 ×2（重校随调参循环）
7. **确定性包围士气**：每脉冲**先算**；4 面起三档减益——4/5/6 面 → −10%/−15%/−25%
   攻防（10 §4 测试值；2026-10-09 评审 C4 统一为三档口径）
8. **结算顺序**：士气 → 行动（势力序玩家先 → 棋子 ID 序）→ 反击/过路费即时触发
   → 账期留桩不实现
9. **随机合法 AI ×2**：合法指令随机生成即可（平推 AI 是 M2 的事）
10. **棋子 3D 原语**：胶囊/方块 + 朝向 + 血条 / 充能黄条（ADR-13 第一代口径）
11. **事件对象化**（ADR-7）：结算产出事件流，UI 只消费事件
12. **测试与校准基建**：headless 回归套（时钟/轴/反击/过路费/冲锋/士气各 ≥1 测）；
    **自战统计工具 = 模拟器 v7**（复用引擎 headless 跑沙盒，出节奏/胜率报表，
    07"三同步"的调参环；**增量交付**——T5 后即可跑双兵种最小报表，2026-10-09 增，评审 S5）
13. **CI 恢复**：Gitee headless 测试门禁（超支可延至收尾，不占关键路径，评审 S8 对账）
14. **最简快照（防呆项，超支首砍，2026-10-09 增——评审 S7）**：`BattleState` 全量
    dump/restore——开发期中断续跑与 bug 复现用（RTwP 连续时间下多目标战斗验证成本高，
    无快照则 3~5 周内核期难以"中途保存再继续"）；正式存档口径仍 = §M2-7

### 验收（证伪清单——不是"做完了"，是"读得出来"）
- [ ] 06 §3.7 三个标准推演可复现：**包抄**（4 面减益 + 多份过路费）、**断后**
      （追兵绕行付税）、**风筝**（M1b 以**弓箭 vs 骑枪**验证同一边界：弓箭走-停-射
      窗口被骑枪追兵抓住——骑弓不在 M1b 四兵种阵容，完整骑弓版随 8 兵种齐后复检；
      **主创 2026-10-09 拍板：维持此口径，骑弓暂不补入**）
- [ ] 暂停改令体验：30 棋子在场上时暂停下达/修改指令无压力、无歧义
- [ ] 3 势力同脉冲争抢（同格争进/同目标争打）按势力序+ID 序确定性结算；

## M2 · 经济与生产 —— "像游戏了"（粗估 4~6 周）

**定义**：从沙盒变成征服游戏——占点、攒钱、造兵、推平。

### 范围
1. **资源终表**：3~4 种资源定名、城/资源点 → 产出映射、囤积上限（09 D-③）
2. **招募体系**：每城 7 格落兵区、逐格排队、满血落地、兵种资源成本（08 重锚）
3. **账期经济结算**：收入入账 / 队列推进 / 附属修复（两层时钟合龙）
4. **附属建筑**：仅主城、概率损坏、半价修复
5. **胜利条件**：占领全图（多条件接口留桩）
6. **平推 AI**：会造兵、占点、推进（"能单挑一个忙碌的朋友"的下限）
7. **存档/读档**：战斗+经济全状态序列化，同 seed 续跑一致（旧 T8 复用思路）。
   **格式口径（2026-10-09 定，ADR-5 配套）**：快照式——存 BattleState 全量（棋子/
   双充能轴/时钟/账期/队列/**反击率当前值等一切运行态**，ADR-12）+ RNG 内部状态，
   非命令日志（命令流+seed 重放仍是
   headless 内部工具）；首字段 `schema_version`；M5 前不承诺跨版本迁移，
   开发期格式可破、破版删档
8. **地图数据化**：`MapData` 落盘为 `MapDef` .tres（04 M1a-T2 运行时类 ↔ 磁盘资源，
   两名一物，2026-10-09 评审 G7 统一命名）+ 固定剧本图（随机生成保留为来源之一）

### 验收
- [ ] 一局从开局到占领全图完整可玩（headless 跑通 + 主创实操）

- [ ] 删 `scripts/ui/**` 后测试仍全绿

## M4 · AI 深化 —— "能单挑电脑"（粗估 3~5 周）

**定义**：电脑方会在正确时机集火、保人、撤退，打得像一个忙碌的朋友。

### 范围（对齐 Wesnoth AI 分层哲学；L0 已随 M1b 落地）
1. **L1 启发式**：威胁评估（可被集火值/充能窗口）、简单集火与保人
2. **L2 战术脚本**：表驱动的战术倾向（激进/防守/保将领），剧本可指定
3. **AI 节律**（09 已拍）：战略每账期 / 战役每 5~10 脉冲 / 战术事件驱动
4. **难度旋钮**：收入乘数 / 白名单 / 反应延迟（数据驱动，不做视野作弊）
5. **自战回归**：autobattle 报表进 CI，平衡性回归测试

### 验收
- [ ] 人机对战 AI 全阶段无非法命令、无死锁（headless 压力 100 局）
- [ ] AI 至少展现集火、撤退两种行为
- [ ] 难度旋钮实测拉开体验差距
